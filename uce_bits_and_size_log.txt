======================================================================
STRUCTURE 1: bit_supply -- the concept behind 'infinite bits'
======================================================================
Comparing implied_bits and pi_digits (Structure: bit_supply)

DIFFERENT:
  origin:
    implied_bits: finite: real bits + a fixed rule
    pi_digits: finite: the definition of pi
  stored:
    implied_bits: only the real bits
    pi_digits: nothing (the definition only)
  access:
    implied_bits: any bit derived on demand, instantly
    pi_digits: any digit computed on demand
  freedom:
    implied_bits: none: every bit fixed by the origin
    pi_digits: none: every digit fixed by the origin
Comparing implied_bits and ram_bits (Structure: bit_supply)

DIFFERENT:
  origin:
    implied_bits: finite: real bits + a fixed rule
    ram_bits: whatever was written, bit by bit
  stored:
    implied_bits: only the real bits
    ram_bits: every bit
  access:
    implied_bits: any bit derived on demand, instantly
    ram_bits: read where it sits
  freedom:
    implied_bits: none: every bit fixed by the origin
    ram_bits: full: each bit set independently
Comparing implied_bits and coin_bits (Structure: bit_supply)

DIFFERENT:
  origin:
    implied_bits: finite: real bits + a fixed rule
    coin_bits: none: no rule, no definition
  stored:
    implied_bits: only the real bits
    coin_bits: nothing until flipped
  access:
    implied_bits: any bit derived on demand, instantly
    coin_bits: only by generating (flipping)
  freedom:
    implied_bits: none: every bit fixed by the origin
    coin_bits: full: each bit independent of all others
